Redline — Hybrid Document Analysis Pipeline
Firebase AI Logic hybrid inference · on-device model as a privacy filter for the cloud model
Stage 1 · On-Device Redaction inference mode: prefer_on_device
1Intake — the lawyer pastes or uploads the contract text inside the app.
2Local extraction — Gemini Nano (Chrome Prompt API) returns sensitive entities as structured JSON: client names, rates, dates, identifiers.
3Redaction preview — review-and-edit UI; the lawyer approves each redaction before anything else happens.
Works offline. No network call in this stage — this is the airplane-mode demo moment.
↓approved redacted draft, locally held
Stage 2 · Consent Gate no inference · local audit
4"What leaves your device" panel — shows the exact outbound payload character by character.
5Explicit consent — cloud analysis starts only after approval; refusal keeps everything local.
6Audit log entry written locally: what was sent, when, and which model ran it.
↓redacted text only — never the original
Stage 3 · Cloud Analysis inference mode: only_in_cloud
7Cloud pass — Gemini Flash analyzes only the redacted text: clause risks, missing terms, plain-language summary.
8Merge & report — findings are mapped back onto the original document held on-device; exportable report + audit trail.
Fallback rule. If Gemini Nano is unavailable (older device or browser), Stage 1 reroutes to the cloud model with a visible "cloud fallback" privacy notice — the user always knows where inference ran.
